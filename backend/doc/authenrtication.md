การยืนยันตัวตนของ Agent (Agent Authentication)

ภาพรวม

Agent Authentication คือกระบวนการตรวจสอบตัวตนของ Agent ก่อนอนุญาตให้เชื่อมต่อและส่งข้อมูล Monitoring ไปยัง Backend

Agent ทำหน้าที่รวบรวมข้อมูลทรัพยากรของเครื่อง เช่น CPU, Memory และ Disk แล้วส่งข้อมูลไปยัง Backend ผ่าน API

ระบบต้องสามารถระบุได้ว่า Agent ที่ส่งข้อมูลเข้ามาเป็น Agent ที่ได้รับอนุญาตให้ใช้งานกับ Server นั้นจริง

1. วัตถุประสงค์

ตรวจสอบตัวตนของ Agent ก่อนรับข้อมูล

ป้องกัน Agent ที่ไม่ได้รับอนุญาตส่งข้อมูลเข้าสู่ระบบ

จำกัดสิทธิ์การส่งข้อมูลตาม Server ที่ได้รับมอบหมาย

ป้องกันการปลอมแปลงตัวตนของ Agent

รองรับการจัดการสิทธิ์และการยกเลิกการเข้าถึง Agent

2. หลักการทำงาน

ผู้ใช้งานลงทะเบียน Server ผ่าน Dashboard

Backend สร้างข้อมูล Server และกำหนด Credential สำหรับ Agent

ผู้ใช้งานนำ Credential ไปตั้งค่าใน Agent

Agent ใช้ Credential เพื่อยืนยันตัวตนเมื่อเรียก API

Backend ตรวจสอบ Credential และสิทธิ์การเข้าถึง

หากผ่านการตรวจสอบ Backend จะอนุญาตให้ Agent ส่งข้อมูล Metrics

หากไม่ผ่านการตรวจสอบ Backend จะปฏิเสธคำขอ

3. การส่งข้อมูล

Agent ส่งข้อมูลไปยัง Backend ผ่าน HTTP Request โดยแนบ Credential สำหรับการยืนยันตัวตน

ข้อมูลที่ส่งประกอบด้วย

Server ID

CPU Usage

Memory Usage

Disk Usage

Timestamp

4. การตรวจสอบสิทธิ์

Backend ต้องตรวจสอบข้อมูลต่อไปนี้ก่อนรับ Metrics

Credential ถูกต้องและยังใช้งานได้

Agent มีสิทธิ์เข้าถึง Server ที่ระบุ

Server ยังอยู่ในสถานะที่อนุญาตให้ส่งข้อมูล

ข้อมูล Metrics มีรูปแบบถูกต้อง

5. การจัดการ Credential

Credential ต้องไม่ถูกจัดเก็บเป็นข้อความธรรมดาในฐานข้อมูล

ควรจัดเก็บในรูปแบบ Hash

ไม่เปิดเผย Credential ใน API Response หรือ Log

สามารถยกเลิก Credential ได้เมื่อจำเป็น

ควรรองรับการออก Credential ใหม่เมื่อมีการเปลี่ยนแปลงหรือรั่วไหล

6. แนวทางด้านความปลอดภัย

ใช้ HTTPS ในการรับส่งข้อมูล

ไม่กำหนด Credential ไว้ใน Source Code

จำกัดสิทธิ์ของ Agent ให้ส่งข้อมูลได้เฉพาะ Server ที่ได้รับอนุญาต

ตรวจสอบ Credential ทุกครั้งที่เรียก API

รองรับการเพิกถอนสิทธิ์การเข้าถึง

7. ผลลัพธ์ที่คาดหวัง

ระบบสามารถตรวจสอบและระบุตัวตนของ Agent ได้อย่างถูกต้อง ป้องกันการส่งข้อมูลจาก Agent ที่ไม่ได้รับอนุญาต และจำกัดการเข้าถึงข้อมูลตาม Server ที่ได้รับมอบหมาย
